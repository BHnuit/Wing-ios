隐私政策

最后更新时间：2026年2月25日

欢迎使用 蝉翼。我们深知隐私对您的重要性，因此我们将“隐私优先”作为本应用的核心设计理念。本隐私政策旨在说明 蝉翼如何处理您的数据。

1. 数据存储与 100% 本地化

您的所有日记内容、图片、语音记录及设置均完全存储在您的设备本地（通过 iOS 的安全数据库）。我们没有任何后端服务器存储您的日记数据，开发者也无法访问、查看或收集您的任何私人记录。

2. 密钥安全 (Keychain)

蝉翼允许您使用第三方 AI 模型进行日记合成。您提供的所有 API Key 均会通过苹果系统最高等级的 Keychain（钥匙串）进行加密安全存储。该信息绝不会被上传至我们的服务器或与其他第三方共享。

3. 第三方 AI 服务与数据共享

当您使用“日记合成”或“记忆提取”等 AI 功能时，特定数据将会通过加密网络发送至您选择的第三方大语言模型提供商。

3.1 共享的数据类型

以下类型的数据可能会被发送至 AI 提供商：

  • 文字碎片：您在聊天界面中作为日常记录输入的文字内容。
  • 图片描述：您附加的图片的描述文本（图片本身不会被发送）。
  • 长期记忆内容（如已启用）：从您以往日记中提取的语义记忆、情景记忆和行为记忆。

3.2 数据收集方式

与 AI 服务共享的所有数据均由您通过应用的聊天界面主动提供。蝉翼不会在未经您主动输入和明确同意的情况下自动收集或传输任何数据。

3.3 用户同意

蝉翼要求您在与第三方 AI 服务共享任何数据之前提供明确同意：

  • 在首次使用任何 AI 功能时，会弹出明确的同意弹窗，解释将共享哪些数据以及共享给谁。
  • 您可以随时在 设置 → 隐私与数据 → 撤回数据共享同意 中撤回您的同意。
  • 撤回同意后，AI 功能将不会发送任何数据，直到您重新授权。

3.4 支持的 AI 提供商

数据将根据您的选择直接从您的设备发送至以下提供商之一：

  • Google Gemini — 服务条款
  • OpenAI — 隐私政策
  • DeepSeek — 隐私政策

蝉翼不运营任何中间服务器。您的数据传输仅发生于您的设备与目标提供商之间。我们强烈建议您在使用前详细阅读所选提供商的官方隐私政策。

4. 数据收集与追踪分析

蝉翼 不含有任何隐藏的追踪脚本、广告 SDK 或用户行为分析工具。我们不会收集您的使用习惯以用于商业或广告目的。您在使用应用时的所有操作均是私密且完全由您自己掌控的。

5. 您的权利

由于所有数据均存储在您的本地设备上：

  • 修改与删除：您可以随时在应用内修改或彻底删除任何日记内容。这会从您的设备上不可逆地抹去对应数据。
  • 数据导出：您可以通过应用内的“数据管理”功能将所有数据以标准格式导出和备份，以便您随时随地拥有您的数据所有权。

6. 本隐私政策的更新

我们可能会适时修改本隐私政策，相关更新将在此页面公布。若有重大变更，我们会在应用内通知您。
