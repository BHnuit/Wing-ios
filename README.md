## 📖 关于蝉翼

捕捉每一个转瞬即逝的思绪回响。

这是一款极简 AI 智能日记应用，旨在消除记录的心理负担，让零散的灵感成为你专属的篇章。

## ✨ 核心功能

- 🎙 **灵感捕捉**：像聊天一样随手记下当下的思绪回响。无需在意排版与逻辑，让记录回归直觉。
- 🧠 **智能合成**：先进 AI 引擎自动将零碎笔记整理成条理清晰、文字优美的日记，重塑碎片价值。
- 🎨 **深度自定义**：从文风笔触到底层 AI 模型，一切皆可随心定义，打造专属你的数字笔尖。
- 📊 **洞察与记忆**：通过直观的数据统计洞悉内心成长，在回溯中见证每日的变化。

「蝉翼」让你的每一次记录都有回响。

## 🚀 安装
